# Project Brief

*   **Core Requirements & Goals:** Develop an "Intelligent Agent-driven Content Production Studio" that leverages advanced AI (LLMs, TTS) to streamline the creation of high-quality educational and marketing scripts and voiceovers. The primary goal is to enhance content quality, reduce manual effort, and integrate AI agents directly into the workflow. Key features include script generation from prompts/references, script editing, voice synthesis with customization, and future capabilities like translation, AI research assistance, and multimedia production.
*   **Scope:**
    *   **In Scope (v0.1.0 / Phase 1 & 2 Complete):** Advanced script generation (DeepSeek R1 primary, Claude 3.7 Sonnet fallback), multiple templates (General Ed, Tech Tutorial, Marketing, Business Training, Music Lesson), script editing, enhanced voice synthesis (ElevenLabs with MP3/OGG/WAV formats, batch generation, custom voice IDs), basic reference input UI (document/URL/YouTube), "Humanize" feature for optimizing voiceover scripts, admin dashboard with authentication, cross-template testing suite UI, token analytics dashboard.
    *   **In Scope (Future Phases):** Full reference content processing (document analysis, YouTube style understanding), multilingual translation (Claude 3.7), AI research/fact-checking (FireCrawl, Perplexity MCP), multimedia generation (Suno AI music, EverArt MCP visuals), professional document exports, user preference memory (Memory MCP), user accounts/history, advanced collaboration, potential monetization tiers.
    *   **Likely Out of Scope (Not Mentioned):** Real-time collaboration, mobile application version (currently Gradio web UI), video editing capabilities (focus is on script/audio/images).
