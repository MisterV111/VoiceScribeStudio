# Archived Tests

This directory contains test scripts that are no longer part of the active testing suite but are preserved for reference and potential future use.

## Files

- `test_openai.py` - Legacy test for OpenAI API connectivity and functionality, preserved for reference as the project has moved to DeepSeek and Claude as primary LLMs.

## Usage Notes

These tests may require additional configuration or updates to work with the current codebase. They are maintained for:

1. Historical reference
2. Potential future integration if these services are needed again
3. Code pattern examples

## Re-activating Tests

If you need to use any of these tests:

1. Review the test code and update imports/dependencies as needed
2. Update the API keys in your `.env` file
3. Test locally before integrating into the main testing workflow
4. Consider moving the file back to the main tests directory if it becomes actively used again
